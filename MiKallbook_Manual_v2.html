1. Introduction

MiKallbook is a stage manager's prompt book. It holds the script with every cue marked on it, and gives you a calling view to run the show from. It is part of the Mi suite: it reads the cue lists of MiKonsole (lighting) and MiKue (sound), and can fire their cues itself when you call GO.

MiKallbook covers:

  • The script as a PDF (including scanned pages) or as pasted text, with a Paper or Dark page
  • GO points marked on the script, each with one or more department cues, Standby and Warn points, a note, and a calling order
  • A concert running order instead of a script, for choir and concert programs
  • Calling the show with GO and Back, with the script following along
  • DRIVE: GO fires the matching cues in MiKonsole and MiKue
  • A show clock for rehearsals and performances: milestones, holds, run times
  • Rehearsal and performance reports, with notes sent from the team's phones
  • Department cue sheets to print or open in Excel
  • Operator mode, linked computers that follow the stage manager, and a Booth View for a second monitor
  • A link to the show's MiKast production: its rehearsal and performance calls become sessions here, and sign-ins fill in the report
⚡ Scripts are copyrighted. MiKallbook never uploads a script anywhere. Linked computers each open their own copy, and only the calling position travels over the network.

System Requirements

  • Windows 10 or later (a Mac build is also available)
  • For cue lists and DRIVE: MiKonsole and MiKue running on the same computer, from 2026-10-17 or later
  • For Link Computers and Notes from Phones: the computers and phones on the same network
  • For the MiKast Link: MiKast from 2026-10-20 or later, and its production where this computer can open it (the same computer, as a rule)

Quick Start

  • Open MiKallbook. It opens in Edit mode with an empty show.
  • Click Import PDF… for the script, or Paste Text…, or Running Order… for a concert
  • Click on the script where a cue is called. Pick the department, check the cue number, and press Enter. Repeat for every cue.
  • Click Save and name the show. MiKallbook creates a show folder and copies the script into it.
  • Click Show and press Space for each GO. Backspace steps back.

4. Show Files

A MiKallbook show is a folder. The first save creates <Show Name>/<Show Name>.mikallbook with a script folder (a copy of the script PDF) and a reports folder (report, cue sheet and running order PDFs). Copy or move the whole folder to take the show to another computer.

ButtonWhat it does
New (Ctrl+N)Starts an empty show
Open (Ctrl+O)Opens a .mikallbook show (or an older .micallbook show)
Save (Ctrl+S)Saves the show. The first save asks for a name and place.
Save As (Ctrl+Shift+S)Saves a copy as a new show folder
  • New, Open, and Exit ask Save changes? when there are unsaved changes
  • If the script PDF can't be found when a show opens, the page area says so. Click Locate PDF… to point MiKallbook at it.
  • Exit with a session running asks whether to End Session or Leave Running. Exit while other computers are following asks first.
  • Some settings are kept on this computer rather than in the show: Paper / Dark, Follow, contrast, zoom, 1 or 2 pages, the Operator department, DRIVE, Booth View's place and contents, and the Link address and code

Older Shows (.micallbook)

Shows made before MiKallbook was renamed have the extension .micallbook. MiKallbook opens them. The show opens marked as having unsaved changes, and the first save writes <Name>.mikallbook in the same folder, leaving the old file as it was.

5. The Script

Importing a PDF

Click Import PDF… (Edit mode). Any PDF works, including scanned pages that are only pictures. On a PDF with real text, a mark snaps to the start of the word you click; on a scanned page it goes exactly where you click.

Pasting Text

For original works, revues, or a script you have typed up, click Paste Text…, paste or type the script, and click Use Text (Ctrl+Enter). Pages are laid out the same on every computer: US Letter, 65 characters a line, 54 lines a page.

  • Rejoin Lines repairs text copied out of a PDF, where every printed line ends in a line break. It joins the paragraphs back together and drops page numbers. MiKallbook offers it when the text looks like that. Ctrl+Z in the text box undoes it.
  • Script layout (on by default) centers character names and indents (stage directions). It changes only how the page looks, not the text.
  • Edit Text… changes the text later. Marks stay on their words; a mark whose words were deleted is flagged so you can check it.
⚡ Switching a show from a PDF to text (or back) keeps every GO point's cues and notes, but not where it sits on the page. Use Place on script… in the Inspector to put each one back.

Viewing

  • ↔ fits the page width to the window; ↕ fits a whole page. Both keep fitting as the window changes size.
  • Paper is a warm cream page, easier on the eyes than white. Dark shows light grey text on dark grey for a dark booth; the PDF itself is never changed. Contrast (Dark only) helps grey scanned pages.
  • In a narrow window the toolbar wraps onto a second row

7. Marking GO Points

A GO point is one place in the script where you say GO. It can carry one cue or several (a combined call such as "LX 12 + SQ 4").

Placing a GO Point (Edit Mode)

  • Click on the script where the cue is called. A quick picker opens at the spot.
  • Pick the department (Tab / Shift+Tab steps through them). The cue number box suggests the next free number; type over it if needed.
  • + Add puts another cue in the same GO point
  • Press Enter to place it, or Esc to cancel

Each GO point gets a tab in the right margin. Its line runs through the margin and the space above the marked line, so it never strikes through the words. Tabs that would overlap stack.

Mic Cues

A department with Mic numbers on (MIC) is called by mics rather than a cue number. In the picker and the Inspector, a mic cue is one or more groups, each a list of mics (4-8, 11) set to IN or OUT (+ Group adds another). It reads MIC 4–8, 11 IN, 2–3 OUT everywhere it appears.

When the show is linked to MiKast and its production has a mic plot, the names of who wears each mic show with the cue: 4 Jane D., 5 Sam P., 6 — (— = no one on that mic). They appear in the tab's tooltip in the script, in Operator mode and the Booth View for this department, and on cue sheets. See 19. MiKast Link.

Milestones

A GO point can carry one milestone: House Open, Places, Act 1 Up, Act 1 Down, and so on up to Act 5 Down. A milestone can be the GO point's only cue (Standby reads HOUSE OPEN), or sit with department cues (ACT 2 DOWN · LX 40, for house lights up at the end). Each milestone can be on one GO point only; setting it on another moves it there. Put pre-show calls at the top of page 1 or on the title page.

In Show mode, calling a milestone GO point logs its time on the show clock. See 12. Show Clock.

8. Concert Running Order

For a choir or concert program, use a running order instead of a script. On a new show's empty screen, click Running Order…. GO points already marked keep their cues and wait to be put on an item.

Building It (Edit Mode)

  • Each item has a kind (Song, Speech, Transition, Riser move, Intermission, Other), a title, an estimated length (m:ss; typing 4 gives 4:00), performers or group, and optional cue lines or lyrics, one per line
  • + Add Item adds one at the end. ▲ ▼ move an item; ✕ deletes it (its GO points can be kept for another item).
  • The header shows the number of items and the total length; each item shows when it starts (+m:ss from the first item)
  • + GO on an item opens the quick picker. Click a GO to select it; the Inspector then sets its Item and On (the start of the item, or one of its cue lines).
  • Calling order follows the items, the start of an item before its lines. Earlier / Later still work; Item order resets.

In Show Mode

The Standby GO's item is highlighted and kept in view, called GO points dim, and clicking a GO sets Standby there. Everything else (GO, Back, DRIVE, Link, Booth View, Operator mode, cue sheets, reports and notes) works as it does with a script.

Printing

Print or Save PDF lists #, item, kind, performers, cue lines, length and start time. With cues adds each item's cues for the crew (Running Order.pdf); without it the file is Running Order - Performers.pdf. Both go in the show's reports folder.

9. Calling the Show

  • Switch to Show mode. Standby shows the next thing to call.
  • Warnings and Standbys are called too. A GO point with Warn and Standby points is called in three steps, in script order: WARNING LX 5 → STANDBY LX 5 → LX 5 GO. The Standby box shows WARNING or STANDBY above the cues, and the big button reads WARN (amber) or STANDBY (yellow) instead of GO. Pressing it on those steps calls them: nothing fires, nothing is logged, and operators see WARN or STANDBY.
  • The steps follow the script: a Warning placed before an earlier GO point is called before that GO point (never after its own GO). A GO point with no Warn or Standby points is called in one step, as before.
  • GO (Space) calls the next step. A second press within 0.3 seconds is ignored.
  • Back (Backspace) steps back one step: a Warning or Standby, or a GO point
  • On the script, the next step's tab is enlarged and its line gets a highlighter band (the GO tab, or the dashed W / SB tab); calls already made are dimmed.
  • Follow (next to Paper / Dark, Show mode only, on by default): the script scrolls so the next call sits about a third of the way down. Turn it off to keep the script where you put it, for example to look ahead; turn it on again to jump back to the next call. It is remembered on this computer.
  • To pick up mid-rehearsal, click a tab (or a running-order row) to set Standby there. A GO tab stands at that GO (Back steps into its Warning and Standby); a W or SB tab stands at that call. Nothing fires.
  • After the last GO, the Standby strip shows END. Back steps back into the show; clicking GO 1 in the list starts the next run fresh.

With DRIVE off, GO only moves your calling position: operators press their own GO. With DRIVE on, GO also fires the cues. See 11. DRIVE.

10. Cue Lists from MiKonsole and MiKue

While MiKonsole and MiKue run on this computer, MiKallbook reads their cue lists for the departments linked to them (LX to MiKonsole, SQ to MiKue). Nothing has to be set up in MiKue. In MiKonsole, open Settings ▸ Phone Remote and click Connect: its cue list only comes through Phone Remote.

Status Pills

The calling column shows a pill for each linked app: green with the number of cues; amber when MiKonsole is running with Phone Remote not connected, or the app is an older version; grey when it is off. Hover over a pill for details.

Using the Lists

  • Quick picker: under the number, what that cue is ("Sunrise", "Doorbell · fires LX 1.5"), and the app's cue list. Click a cue, or use ↑ ↓ in the number box to step through it. Typing any number still works.
  • Inspector: the same line under each cue, and the number boxes offer the list as a dropdown
  • A cue that isn't in the app's list gets a wavy red underline on its tab and a red line in the Inspector, and the calling column shows "n not found" (click it to go to the first). Nothing is flagged while an app isn't running.
  • MiKonsole sends its cue list when Phone Remote connects, and on GO, Back, Stop and Go To. After opening a show or editing cues in MiKonsole, press GO there once (or Disconnect and Connect) to refresh MiKallbook's list.

Combo Cues

When a MiKue cue fires a MiKonsole cue (itself, or further along its Continue / Follow chain), MiKallbook adds that LX cue to the GO point, and the tab reads LX 1.5 / SQ 2. A combo cue can't be edited on its own: changing or removing the SQ cue updates it. An LX cue you typed in yourself that MiKue also fires becomes the combo cue. A MiKue cue that just sends GO to MiKonsole shows as "LX next". If MiKue's cues change later, the Inspector offers Update from MiKue.

11. DRIVE

With DRIVE on, calling GO in MiKallbook fires the GO point's cues in MiKonsole and MiKue at the same moment, so nobody presses GO in those apps.

Turning It On

  • Entering Show mode at the start of a run asks Drive MiKonsole and MiKue? (naming only the apps this show's departments are linked to): Drive (Enter), Call Only, or Cancel (Esc)
  • The DRIVE button next to Back changes it during the show (remembered on this computer)
  • With DRIVE on, the Show mode bar turns red: GO DRIVES MiKonsole + MiKue. With DRIVE off it is amber: DRIVE OFF · GO doesn't fire MiKonsole + MiKue.

What Happens

ActionWith DRIVE on
GOFires each cue in its department's linked app: LX cues in MiKonsole, SQ cues in MiKue. MiKonsole's cue is found by its number at that moment, so cues inserted in MiKonsole don't shift anything. For a combo cue only the SQ cue is sent, and MiKue fires the light, so it never fires twice.
BackSends Back to MiKonsole if the GO point being stepped back over changed the lights. Stops the sounds that GO point started in MiKue (each SQ cue and whatever it set off, with a 1-second fade). Sounds started earlier, such as pre-show music, keep playing.
StandbyMiKue's Standby follows MiKallbook's: it is set to the next SQ cue from your calling position
  • A cue that can't be sent never stops the show. MiKallbook moves on, the GO button flashes red, and a message says what wasn't sent and why (not in the app's list, Phone Remote not connected, MiKue not running…)
  • Each app is only needed for the departments linked to it. For a sound-only show, set LX's Link to None (or delete LX) so nothing waits on MiKonsole.
  • MiKonsole and MiKue must run on this computer, with MiKonsole's Phone Remote on Connect
  • DRIVE never fires in Edit or Operator mode, or on a computer following the stage manager

12. Show Clock

A session is one rehearsal or performance. The timing box sits in the calling column below Back and DRIVE, in Show mode, on the stage manager's computer.

Running a Session

  • Start Session asks the kind: Rehearsal, Tech, Dress, Preview or Performance (Enter = Performance). Each kind is numbered on its own (Performance 3). In a show linked to MiKast, today's MiKast calls are listed first by name and time (Rehearsal 5 · 10:30 AM · Main stage); Enter starts the nearest one. See 19. MiKast Link.
  • The big button then logs the next milestone: House Open → Places → Act 1 Up → Act 1 Down → Act 2 Up … → the last act Down, then End Session. A second click within 1 second is ignored.
  • The box shows where the show is (HOUSE OPEN, PLACES, ACT 2, INTERMISSION, SHOW DOWN) and the time since then, with a line of run times: Act 1 1:00:00 · Int 15:00 · Act 2 … · Held 5:00
  • Hold starts and ends a hold, and the box turns red. Pick a reason while it runs (Late house, Technical, Cast, Audience, Weather, Other). An act going Up ends a hold.

With Milestone Cues

When the show has milestones on its GO points (see Milestones), calling them logs the times instead of the big button:

  • With no session running, the first milestone GO starts one, of the kind chosen when Show mode started
  • The last act's Down ends the session (Reopen it in the Session Log if that was early)
  • Back over a milestone GO point takes its time out again
  • The timing box keeps Hold, the reason, and the Session Log

Session Log

Session Log opens the times of any session of the show (newest first, from the menu at the top). In it you can:

  • Change any time, for a milestone pressed late, or delete one
  • Add a milestone or another moment ("Pre-show speech") at a typed time, or a hold that wasn't pressed
  • Set the kind, number, date and number of acts (1–5)
  • End, Reopen or Delete the session

Run times: each act from its Up to its Down (holds inside an act are shown); intermission from one act's Down to the next act's Up; running time from the first Up to the last Down.

  • Only one session runs at a time. It keeps running in Edit mode, and is saved with the show: open the show again and it carries on.
  • Until the show is saved, the running session is also kept on this computer. If MiKallbook closes without saving, opening the show again offers to restore the times.

13. Reports

Every session has a report. Open Utilities ▸ Reports, or Report in the Session Log.

  • Left: this show's sessions, newest first, with how many fields are filled in. + New Report adds one for a rehearsal that wasn't timed. In a show linked to MiKast, the calls still to come are listed first, under Coming up (from MiKast), soonest first; then Sessions so far.
  • Right: the report. Times come from the show clock, with holds and other moments; Edit Times opens the Session Log. Then the template's fields.
  • Typing marks the show as changed. Ctrl+S saves without leaving the window. Report text has the same crash protection as session times.
  • Save PDF writes reports\<date> <Kind n>.pdf in the show folder (saving again replaces it), then offers Open PDF or Show in Folder. A show that has never been saved asks to be saved first.
  • Print (Ctrl+P) opens the printer dialog. Both use a Letter-size page.
  • Esc closes the window. GO and Back don't respond while it is open.

The Template

The suggested template has: Stage manager, Call time, House count, Absent / late, Called, General, one field per department, Scenic & props, Costumes, hair & makeup, Cast, Front of house, Injuries & safety, and Next call.

Edit Template renames, changes the kind of, reorders (▲ ▼) or deletes fields, and + Add field adds one. Field kinds: one line, several lines, number, time (a clock picker), and yes / no. Carry forward starts each new report with the last report's entry (useful for Stage manager and Next call). Use Suggested Fields resets the template, keeping entries in fields with the same name.

14. Notes from Phones

Directors, choreographers, music directors and others can send rehearsal notes from their own phones or laptops straight into the report.

  • Open Utilities ▸ Notes from Phones (or Take Notes from Phones in the Reports window). This starts sharing if this computer isn't already, and shows a large QR code, the address (http://<this computer>:8095/notes) and a 4-digit code.
  • Scanning the QR code opens the notes page with the code filled in. Any browser on the same network works.
  • On the notes page: name and role (remembered on that device), Note for (the template's several-lines fields: General, each department, Cast…), Cue (if needed) with a Last button for the GO point called last, the note, and Send Note (Ctrl+Enter on a laptop)
  • Each note is added to the end of that field, for example LX 12 · Jane (Director): Spot late on entrance. If the report is open the box flashes green; a message shows either way.
  • Notes go to the running session's report, else the latest report dated today, else a new Rehearsal report made by the first note
⚡ Notes can only add text to a report. Nothing on the notes page can change anything else in MiKallbook. A wrong code is refused.

16. Operator Mode

For a light, sound, spot or deck operator. Click Operator and pick the department in the menu beside it (remembered on this computer). The window shows only that department:

  • The next cue, large, with its state against the stage manager's calling position: WAITING (two or more GOs away), WARN (the GO after the stage manager's Standby), STANDBY, and GO (green, just fired). A cue with its own Warn and Standby points follows the stage manager's calls instead: WARN once the Warning has been called, STANDBY once the Standby has (or when it is the next GO), WAITING until then. Other cues in the same GO show as "with SQ 4". Note and VISUAL included. For mic cues, the names of who wears the mics show under the cue (from MiKast).
  • A script excerpt: the lines around the cue's Warn (W), Standby (SB) and GO, with the GO line highlighted. It follows Paper / Dark.
  • The next two cues, each with a short excerpt

It follows this computer's calling (Space / Backspace here), or the stage manager's computer when linked. See 17. Link Computers.

17. Link Computers

Every computer opens its own copy of the same show folder. The stage manager's MiKallbook shares; the others join and follow.

Stage Manager

  • Utilities ▸ Link Computers ▸ Start Sharing. The window shows this computer's address (for example 192.168.1.20) and a 4-digit code, and lists the computers following.
  • The code stays the same from night to night. New Code disconnects everyone.
  • The header shows a blue Sharing · n button; click it to open the Link window

Operators

  • Utilities ▸ Link Computers, type the stage manager's address and code, and click Join (both are remembered). The header shows Linked.
  • Standby, GO (with the green flash) and Back all come from the stage manager. Space and Backspace do nothing here.
  • LINK LOST: a red banner and button. MiKallbook keeps trying to reconnect every 1.5 seconds. Until it's back, Space and Backspace work on this computer; when it reconnects the stage manager's position takes over again.

Copies That Differ

Each show file has a hidden ID, and the stage manager's computer sends a check of every GO point. If this copy differs (GO points changed, missing or extra, or a different calling order), a yellow banner lists them. A different show entirely gets a red banner and isn't followed.

Network

  • All computers must be on the same network, and the network must be set to Private in Windows
  • When Windows Firewall asks, allow MiKallbook on Private networks
  • MiKallbook uses port 8095 (8096–8099 if that one is taken; the address then shows :port)
  • Only the calling position and checks go over the network, never the script. Operators can't control the stage manager's computer.

18. Booth View

Utilities ▸ Booth View opens a second window for a booth monitor. It stays dark. The menu in its top bar picks what it shows (remembered on this computer):

  • Full call: the Standby cues in large type (with WARNING or STANDBY above them when that is the next call) with the note and VISUAL, "GO n of N · page", the last cue called, the next three, a clock, and a green flash on each GO
  • One department: the Operator view for that department (WAITING / WARN / STANDBY / GO, the next cue with its script excerpt and, for mic cues, who wears the mics, and the next two cues), whatever mode the main window is in
  • The top bar says SHOW, OPERATOR, EDIT · not calling, FOLLOWING THE SM, or LINK LOST (red)
  • The first time, it opens on another monitor if there is one. After that it remembers its monitor, position, size and full screen.
  • F11 or a double-click toggles full screen
  • Space and Backspace pressed while it is in front are GO and Back in MiKallbook
  • Close it with its window ✕ or from the Utilities menu. Closing MiKallbook closes it.

19. MiKast Link

MiKast keeps the company list, the rehearsal and performance calls, and who signs in. Link a show to its MiKast production and the two work as one show: each MiKast call becomes a session here, ready to start, and its report fills itself in from the sign-ins.

Linking

  • Utilities ▸ MiKast Link › Choose Production… and pick the production's .mikast file. The show remembers it (save the show to keep the link).
  • If the two show folders sit side by side (for example Shows\Les Mis and Shows\Les Mis MiKast), the link keeps working when both are moved or copied together.
  • The MiKast pill in the calling column shows the link: green with the number of calls, amber if the file can't be found or read. Click it for the MiKast Link window, which shows the production, its file, when it was last read, and the sessions made from it. Choose Another… links a different production; Unlink ends the link.
⚡ MiKallbook only reads MiKast's files; it never changes them. Calls come through when MiKast saves. Sign-ins come through the moment they happen, because MiKast writes them straight away. MiKallbook checks every 2 seconds.

Calls Become Sessions

  • Each call becomes a planned session with the same kind and date, numbered by date after the sessions of its kind that have already happened (Rehearsal 4, 5, 6…).
  • A session made here before linking, on the same date and of the same kind, is matched to its call rather than doubled.
  • The Reports window lists planned sessions under Coming up (from MiKast), soonest first, each with its call time; today's reads today. A planned session's report can be opened and written in ahead of time.
  • Start Session lists today's MiKast calls first, by name and time, with the nearest one ready (Enter). Click one to time that session. The kinds below it (Rehearsal, Tech…) make a session MiKast doesn't know about.
  • In a show with milestone cues, the Session menu in the Show-mode question lists today's calls the same way; the first milestone GO starts the one picked. With nothing picked, it takes today's call nearest the time.
  • Start in the Session Log starts the planned session shown (for a call on another day). Back over the first milestone makes a session planned again.
  • Started the wrong kind? Change Kind in the Session Log. If that day has a MiKast call of the new kind, MiKallbook offers Move to Rehearsal 5: the times, holds and report notes move onto that call's session, and the wrong session is removed. MiKast's own fields (Call time, Absent / late, Called, Next call) keep MiKast's values. Just Change Kind only renames it.
  • Until it starts, a planned session follows its call: a new date or kind in MiKast changes it here too.
  • A call deleted in MiKast removes its planned session if nothing has been written in it. Otherwise the session stays, crossed out in the list and marked call removed in MiKast.
  • Deleting a planned session here (Session Log ▸ Delete Session) is final: it doesn't come back from MiKast.

A field keeps updating while it holds what MiKast put there. Once you type in it, it is yours for that report and MiKast leaves it alone. Names are the names people sign in as. Phone numbers and other contact details never come into MiKallbook.

Mic Names

MiKast's Main mic plot names the person on each mic. MIC cues then show them: MIC 4–6 IN with 4 Jane D., 5 Sam P., 6 —. A cue with both IN and OUT labels each part (OUT: 2 Bob B. · IN: 4 Ann A.).

  • Where: the MIC tab's tooltip in the script (GO, Standby and Warn tabs), Operator mode and the Booth View for the MIC department (the cue and the next two), and cue sheets (printed, PDF and the CSV's Mic names column).
  • Names change when MiKast saves a new plot. MiKast's other plots (swaps for Act 2 and so on) stay in MiKast; MiKallbook uses Main.
  • Not linked, or no mic plot in MiKast: mic cues look as before.

Unlinking

Unlink asks first. Planned sessions not used yet are removed. Sessions already timed, or with anything written in their report, stay as ordinary sessions.
